# Provider Logos

Place provider logo images here. Novora's Integrations page will automatically display them.

## Supported files

| Filename            | Provider    | Format   |
|---------------------|-------------|----------|
| `elevenlabs.png`    | ElevenLabs  | PNG/SVG  |
| `twilio.png`        | Twilio      | PNG/SVG  |
| `assemblyai.png`    | AssemblyAI  | PNG/SVG  |

## Notes

- Recommended size: **64×64px** or larger (displayed at 32×32px)
- Both PNG and SVG formats work well
- If a file is missing, a branded icon fallback is shown automatically
- Transparent backgrounds preferred for dark/light mode compatibility
